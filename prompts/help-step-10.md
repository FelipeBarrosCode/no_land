## Explore Settings in Noland Connect

The Settings page lets you customize your Noland experience. Access it from the dashboard toolbar.

### Available sections:

### Profile
- Change your platform username and password
- Update your Vast.ai API key
- Save platform credentials

### Server Preferences
- Default minimum host reliability (recommended: 0.85)
- Default storage allocation (GB)
- Template hash (the Vast.ai image used for your server)
- Default pricing filters
- Geolocation country preference
- Toggles for verified hosts, AVX requirement, offer types

### Client (Streaming)
- **Bitrate** — video quality (20-150 Mbps, higher for 4K)
- **FPS** — frames per second (30, 60, 120)
- **Resolution** — stream width/height (1920x1080, 2560x1440, 3840x2160)
- **Codec** — Automatic, H.264, HEVC (H.265), or AV1
- **Decoder** — Automatic, software, or hardware decode
- **Audio** — Play locally or on the cloud machine
- Advanced toggles: V-Sync, HDR, frame pacing, performance overlay, gamepad mouse mode

### Shared Storage
- Connect a cloud provider to back up your applications
- 14 supported providers including Backblaze B2, S3, R2, Google Drive, OneDrive, Dropbox
- Test connection, view repository info, disconnect

### Connection
- Select WireGuard as your connection provider (default, managed automatically)
